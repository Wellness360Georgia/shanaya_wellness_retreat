# Shanaya Wellness Svaneti Retreat — сайт

Одностраничный сайт для GitHub Pages: три языка (EN/RU/KA), карта, календарь занятости, форма брони в WhatsApp.

## 1. Загрузка на GitHub Pages

1. На github.com создайте репозиторий, например `shanaya-retreat` (Public).
2. Загрузите в него содержимое этой папки: `index.html`, папку `assets`, этот файл.
3. В репозитории: Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → Save.
4. Через пару минут сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/shanaya-retreat/`.

## 2. Фотографии

Положите файлы в папку `assets` с точными именами:

| Файл | Где на сайте |
|---|---|
| `hero.jpg` | главный экран (горизонтальное, лучше 2000+ px по ширине) |
| `photo-1.jpg` | большая карточка галереи: практика в зале |
| `photo-2.jpg` | купольный зал |
| `photo-3.jpg` | эко-коттедж |
| `photo-4.jpg` | сауна и пруд |
| `photo-5.jpg` | общий стол |

## 2а. Telegram

Ник Telegram задаётся в `index.html` строкой `const TELEGRAM = "";` (без @). Пока строка пустая, кнопки Telegram скрыты и работает только WhatsApp.

Пока файлов нет, сайт показывает аккуратные заглушки, ничего не ломается.

## 3. Календарь занятости

1. В Google Календаре создайте отдельный календарь «Shanaya занятость».
2. Настройки календаря → «Разрешения на доступ» → включите «Сделать общедоступным», видимость «Только сведения о занятости» или полные сведения.
3. Там же найдите «Идентификатор календаря» (вида `abc123...@group.calendar.google.com`), скопируйте.
4. Откройте `index.html`, найдите строку `const CALENDAR_ID = "";` и вставьте ID между кавычками. Сохраните и загрузите файл в репозиторий заново.
5. Занятые даты отмечайте событиями в этом календаре, сайт подтянет их сам.

## 4. Контакты и цена

Номер WhatsApp задан в `index.html` строкой `const WHATSAPP = "995555932437";`. Цена и тексты меняются в словаре `T` там же: три блока `en`, `ru`, `ka`, ключи одинаковые.
